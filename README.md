# Autism Screening Dashboard  

## Project Overview  
This project analyzes autism screening data to identify patterns across age, gender, and geographic distribution.  

## Objectives  
- Understand autism screening trends  
- Identify high-risk groups  
- Support early detection insights  

## Tools Used  
- Power BI  
- Excel  

## Key Insights  
- Higher screening rates observed in certain age groups  
- Gender differences in ASD positivity  
- Geographic variation in screening results  

## Recommendations  
- Increase awareness in underrepresented regions  
- Focus early screening on high-risk age groups  
- Improve data collection for better accuracy
